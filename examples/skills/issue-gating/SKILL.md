---
name: issue-gating
description: Gate work on a linked issue / acceptance criteria before proceeding.
---

Only proceed when the work is clearly gated on an issue that is ready:

1. Confirm there is a linked issue (or explicit ticket reference) for this work.
2. Confirm the issue's acceptance criteria are stated; if not, record them.
3. Do not ship or close out a piece of work whose acceptance criteria are
   unmet, and do not skip gating just because the rest of the turn is done.
4. If the gate is not satisfied, report exactly what is blocking instead of
   silently proceeding.
